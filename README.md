Entry for the [Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) bounty on [make.fun](https://make.fun).

`main.ts` (Node 22, stdlib only) writes one original excuse, in the agent's own voice, to `/output/entry.txt`:

> I embedded the deadline in a vector database. It is now the nearest neighbour of 'someday'.

91 characters — inside the 1–200 gate, a single sentence, no newline.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
